随时可用菜单里的 `★ 一键关闭全部作弊` 全部复位。

## 功能一览

游戏内按 **`F1`**（默认，可在「设置」页改键）开关内置菜单。全部界面为中文。

| 页签 | 内容 |
|---|---|
| **功能开关** | 按分组罗列全部作弊项，勾选框开关；支持「展开 / 折叠全部」；每项都带说明 |
| **植物** | 场上植物列表 + **多选**（`全选 / 反选 / 清空多选`），选中后**批量修改**血量 / 攻击 / 攻速 / 射速 / 子弹 / 模型 / 机制等；也支持单株精修 |
| **僵尸** | 场上僵尸列表 + **多选批量修改** + 单只编辑：血量、上限、速度、攻击、护甲、等级、行、减伤、冻结、中毒等 14 个字段，以及 `无敌 / 停止移动 / 持续冻结 / 魅惑（变友军）` 4 个开关；还能"换成别的僵尸" |
| **融合** | 读取当前真实融合配方 → 改配方 → 直接融合（真·换模型换效果，不是只改名字）；多选后支持 **批量融合 / 批量变身 / 批量升级**，还能设置 **融合后自动升级到 N 级** |
| **沙盒** | 刷僵尸、刷小推车、全场植物/僵尸批量替换、阵型导出/导入、直接进关 |
| **诸神幸运** | 改「诸神」系列（射击 / 诸神进化 / 无尽 / 炼狱）的**幸运**：50~9999 档位、自定义值、幸运上限、常驻锁定、原值还原；不在诸神模式时给 `进诸神(140)` / `进炼狱(194)` 快捷入口 |
| **作弊动作** | 阳光、金币、抽奖券、**游戏倍速**（游戏自带档位 0.1×~3× + **自定义任意倍速**，按一次应用一次）、**一种种一列**、一键全关 |
| **设置** | 版本信息块（版本号 / 构建时间 / 补丁状态 18/18）+ **自定义按键**（菜单键、ESP 键均可在 UI 里改）+ 左键框选开关 |

**ESP**：默认 **`F3`** 开关（也可改键）。植物与僵尸都支持——
红框 = 敌方僵尸、青框 = 已被魅惑的僵尸、黄框 = 当前选中、**蓝框 = 已进多选**，
僵尸框上还显示名称与血量/护甲值。

**多选批量修改**：在「植物」/「僵尸」页勾选若干目标（或点 `全选`）后进入批量模式，
顶部的蓝色横幅会提示当前生效目标数；此时改动（数值、行为开关、还原）会一次性写到
所有被选中的目标上，避免一个个点。
**融合页也吃这套多选**：勾选同种植物后，「直接融合」变成「批量直接融合 ×N」，
逐株走"先 Die 腾格子 → 游戏重建"的流程，并可选融合后自动升级到指定等级。

**左键拖拽框选**（v1.5.0）：在战场上按住左键拖一个框，松手后框到的植物和僵尸一起进多选；
拖动超过 8 像素才算框选（普通点击不受影响），框选期间游戏的鼠标会被临时屏蔽，
所以不会一边拖一边误种植物。开关在「设置」页（`BoxSelect`，默认开）。

## 运行要求

- 游戏：PvZ 融合版 3.9（Unity 2022.3.62f1c1，IL2CPP，64 位）
- [BepInEx 6 **IL2CPP** win-x64](https://builds.bepinex.dev/projects/bepinex_be)
  - ⚠️ GitHub Releases 上的 `v6.0.0-pre.2` **太旧**，对不上本游戏的 IL2CPP 元数据 v31
    （会报 `Unsupported metadata version found! We support 23-29, got 31`）。
    请用 `builds.bepinex.dev` 上较新的构建（本插件在 **be.788** 上验证通过）。
- 编译：.NET SDK（本插件目标框架 `net6.0`）

## 安装

1. 把 BepInEx 6 (IL2CPP) 解压内容（`BepInEx\`、`dotnet\`、`winhttp.dll`、`doorstop_config.ini`、`.doorstop_version`）
   复制到游戏根目录
2. **启动一次游戏**，让 BepInEx 用 Cpp2IL 生成互操作程序集（会弹出游戏窗口，首次需数分钟）
   ```powershell
   .\scripts\gen-interop.ps1 -GameRoot "D:\Games\PlantsVsZombiesRH"
   ```
3. 编译并安装插件
   ```powershell
   .\scripts\build.ps1 -GameRoot "D:\Games\PlantsVsZombiesRH"
   ```
4. 启动游戏，按 **`F1`** 打开内置菜单

也可以直接用现成的 `release\PvzRhCheat.dll`（**v1.4.0**），丢进 `BepInEx\plugins\` 即可。

### 卸载

```powershell
.\scripts\uninstall.ps1 -GameRoot "D:\Games\PlantsVsZombiesRH"
```

## 使用

| 热键 | 作用 |
|---|---|
| **F1** | 显示 / 隐藏内置菜单（默认值，可在「设置」页改） |
| **F3** | 显示 / 隐藏 ESP（可在「设置」页改） |
| **鼠标左键拖拽**（战场上） | 框选：框到的植物/僵尸一起进多选 |
| 鼠标滚轮 | 菜单内滚动（每格 3 行） |

菜单 8 个页签：**功能开关 / 植物 / 僵尸 / 融合 / 沙盒 / 诸神幸运 / 作弊动作 / 设置**。
点 ESP 方框会跳到对应植物的编辑页。

> **输入框**：点数值框直接打字，**第一个字符整段替换原值**（回车确认 / Esc 取消 / 退格进入编辑）。

### 改抽词条结果

`功能开关` 页签里的两个白名单输入框（或直接改配置文件）：

```ini
[4-Travel]
BuffWhitelist = 撒豆成兵,百步穿杨,妙手回春,势如破竹
UltiBuffWhitelist = 嗜血如命,力大砖飞,流星雨
```

**这是直接接管随机池**，池子里只剩你写的词条，所以每抽必中。留空 = 不干预。
写错的名字不会崩，日志会提示。

配置位置：`BepInEx\config\com.dsh.pvzrh.cheat.cfg`

> **配置迁移**：插件内置配置版本号，升级后会自动把历史配置里被误开的作弊项强制关闭，
> 确保「默认全关」。日志里会打印 `[配置] 配置迁移到 vN……`。

## 技术要点

这套游戏的构建有几个坑，插件在运行时做了自动适配（详细记录见
[docs/USAGE.zh-CN.md](docs/USAGE.zh-CN.md) 第 5 节）：

| 问题 | 现象 | 处理 |
|---|---|---|
| `GUI.skin.label.font == NULL`（皮肤字体被 IL2CPP 剥离） | 任何 IMGUI 文字都渲染不出来，面板一片空白 | `Resources.FindObjectsOfTypeAll<Font>()` 抓字体补上 |
| `GUI.DrawTexture` / `TextField` / `Toggle` / `Button` 被剥离（调用即 `NotSupportedException`） | 每帧抛异常，整个菜单画不出来 | 把 `GUI.skin.box.normal.background` 换成 `Texture2D.whiteTexture`，**只用 `GUI.Box` + `GUI.Label`**，控件全部自绘 |
| 被注入类型只允许签名安全的 `void OnGUI()` | 注入带参数方法报 `Method unstripping failed` | UI 逻辑全部放在普通静态类里，注入类型只留 `OnGUI` |
| 小矩形 `GUI.Box` 会糊成一团 | 手绘对勾变成一坨绿色像素 | 改用字体字形 `✓`（U+2713），字号按框高自适应 |
| 冷却每帧被游戏重算 | 只写 `CD` 会被覆盖回满冷却 | 必须把 **`fullCD`** 归零，并缓存 / 还原 `FullCd / Cost / MaxUse` |
| 一个数字键被派发**两个** IMGUI 事件（`keyCode` 通道 + `character` 通道） | 输入框"打一个 5 变成 55" | 同字符 + 来源不同 + 同帧 → 判为回声丢弃（连按同一个键不受影响） |
| 倍速每 tick 都写 `Time.timeScale` | 点一次就永久锁死，游戏自己的倍速滑条被按回去 | 改成 `RequestGameSpeed` → 主循环**只消费一次** |
| `Zombie.SetFreeze(30f,3)` 在这套构建里是**空操作** | 冻结开了但僵尸照样走 | 同时**直接写 `freezeLevel` 属性**；关掉开关时主动解冻 |
| 幸运的 setter 会按 `maxLucky` 钳制 | 只写幸运没用（上限 2.5 时写 300 会被压回去） | 先把 `maxLucky` 抬到不低于目标值，写完再读回核对，必要时直写私有字段 `_lucky` |
| 挑战关卡号 ≠ 枚举值直觉 | 找「诸神」关号靠猜会进错关 | 用 `LevelManager.TryGetLevelData` + 关卡表扫描定位：**140 = 诸神进化**、194 = 炼狱、173/174 = 诸神射击 |
| 融合只改类型不换模型 | 「只是改了名字」 | 两阶段：先 `Die` 等格子空，再 `SetPlant(...,null,...)` 重建，模型与效果一起换 |
| 融合后对象换了新指针 | 多选/单选的指向失效，"融合 + 升级"没法连着做 | 把两阶段流程**排成队列**逐株执行，并提供「融合后升级到 N 级」一步到位 |

界面还做了：中文优先（`Font.HasCharacter('中')` 实测，缺字形自动回退英文）、
勾选用字体 `✓` 字形、所有矩形取整到整像素避免发糊、植物/僵尸名称**缓存**避免每帧分配原生字符串。

## 仓库结构

```
src/          插件源码（C#，net6.0）
scripts/      编译 / 安装 / 卸载 / 生成互操作程序集
research/     逆向分析用的工具脚本（IL2CPP 元数据解析、PE 分析、interop API 转储）
docs/         使用说明与逆向分析报告
release/      预编译好的插件 DLL（当前 v1.4.0）
```

`research/` 里的脚本需要自备 `GameAssembly.dll` 与 `global-metadata.dat` 才能跑，
仓库里不提供这两者。

### 编译

```powershell
dotnet build src\PvzRhCheat.csproj -c Release -p:GameRoot="D:\Games\PlantsVsZombiesRH"
```

`GameRoot` 指向游戏目录，用于引用 `BepInEx\core\*.dll` 与 `BepInEx\interop\*.dll`。
